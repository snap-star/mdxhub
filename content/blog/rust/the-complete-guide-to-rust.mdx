## Learning Path

| Level | Topics | Goal |
|-------|--------|------|
| **Junior** <Badge variant="green">Newbie</Badge> | Variables, types, ownership, borrowing, structs, enums, pattern matching | Write safe Rust programs confidently |
| **Intermediate** <Badge variant="orange">Apprentice</Badge> | Error handling, generics, traits, lifetimes, closures, iterators, testing, smart pointers | Build real-world applications |
| **Expert** <Badge variant="red">Master</Badge> | Unsafe Rust, concurrency, async/await, macros, Pin, FFI, performance | Architect production-grade systems |

## How to Read This Guide

We use a <Badge variant="green">Junior</Badge> → <Badge variant="orange">Intermediate</Badge> → <Badge variant="red">Expert</Badge> badge system to indicate difficulty levels. Each section builds on the previous. Junior sections must be mastered before Intermediate. Intermediate patterns are assumed knowledge in Expert sections.

**Run every example.** Rust is best learned by doing. Use the Rust Playground or create a local project with `cargo new` to experiment.

<Callout type="tip" title="Pro Tip">
Rust has a famously steep learning curve, especially around ownership and lifetimes. Don't be discouraged if concepts take time to click — this is normal! The borrow checker is your ally, not your enemy.
</Callout>
