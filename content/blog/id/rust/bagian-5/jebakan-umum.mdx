# Bagian 5: Jebakan Umum & Praktik Terbaik

## Bab 1: Masalah Borrow Checker

<Badge variant="red">Expert</Badge>

### 1.1 Double Borrow

```rust
// ❌ Masalah: meminjam sebagai mutable saat immutable masih ada
fn main() {
    let mut v = vec![1, 2, 3];
    let first = &v[0];  // Immutable borrow
    v.push(4);          // ❌ Tidak bisa borrow v sebagai mutable
    println!("{first}");
}

// ✅ Solusi: copy nilai (tanpa borrow)
fn main() {
    let mut v = vec![1, 2, 3];
    let first = v[0];   // Copy nilai
    v.push(4);          // ✅ Bekerja
    println!("{first}");
}
```

### 1.2 Struktur Self-Referential

```rust
// ❌ Struct dengan field yang mereferensi field lain
// struct SelfRef {
//     data: String,
//     reference: &str,  // Akan menunjuk ke data
// }

// ✅ Solusi 1: Gunakan index
struct SelfRefIdiomatic {
    data: Vec<String>,
    index: usize,
}

// ✅ Solusi 2: Gunakan Rc + RefCell
use std::cell::RefCell;
use std::rc::Rc;

struct Graph {
    nodes: Vec<Rc<RefCell<Node>>>,
}
```

### 1.3 NLL (Non-Lexical Lifetime)

```rust
// Sebelum NLL (Rust ≤2015), kode ini tidak akan kompilasi:
fn main() {
    let mut x = 5;
    let y = &x;
    println!("{y}");  // y terakhir digunakan di sini
    let z = &mut x;   // ✅ Bekerja dengan NLL (Rust 2018+)
    *z += 1;
}
```

## Bab 2: Kesalahan Lifetime

<Badge variant="orange">Menengah</Badge>

### 2.1 Over-Annotation

```rust
// ❌ Tidak perlu — Rust sudah mengelide ini dengan benar
fn first_word<'a>(s: &'a str) -> &'a str { ... }

// ✅ Biarkan elision bekerja
fn first_word(s: &str) -> &str { ... }
```

### 2.2 Lifetime Elision Gotchas

```rust
// Aturan: setiap input reference mendapat lifetime sendiri
// fn foo(x: &str, y: &str) -> &str  // ❌ Ambigu
// Tidak dielide karena ambigu mana input yang outputnya referensi

fn foo<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() { x } else { y }
}
```

### 2.3 Penyalahgunaan `'static`

```rust
// 'static berarti "hidup selama program" — bukan "abadi"
use std::thread;

fn spawn_task() {
    let data = vec![1, 2, 3];

    // ✅ Pindahkan kepemilikan ke closure:
    thread::spawn(move || {
        println!("{data:?}");
    });
    // data sekarang dimiliki oleh closure
}
```

## Bab 3: Jebakan Async

<Badge variant="red">Expert</Badge>

### 3.1 Blocking di Konteks Async

```rust
// ❌ BURUK: memblokir seluruh runtime async
async fn handle_request() {
    expensive_cpu_operation();  // Memblokir thread!
}

// ✅ BAIK: offload ke thread pool blocking
async fn handle_request() {
    let result = tokio::task::spawn_blocking(|| {
        expensive_cpu_operation()
    }).await.unwrap();
}
```

### 3.2 Fungsi Async Rekursif

```rust
// ❌ Future rekursif perlu Box-pinned
async fn recursive(n: u32) {
    if n > 0 {
        recursive(n - 1).await;  // ❌ Ukuran future tidak bisa ditentukan
    }
}

// ✅ Solusi: gunakan Box<dyn Future>
fn recursive(n: u32) -> Pin<Box<dyn Future<Output = ()>>> {
    Box::pin(async move {
        if n > 0 {
            recursive(n - 1).await;
        }
    })
}
```

### 3.3 Memegang Lock di `.await`


## Bab 4: Panic & Error Umum

<Badge variant="orange">Menengah</Badge>

### 4.1 Index Out of Bounds

```rust
fn main() {
    let v = vec![1, 2, 3];

    // ❌ Panic jika index di luar batas
    // let val = v[5];

    // ✅ Alternatif aman
    if let Some(val) = v.get(5) {
        println!("{val}");
    } else {
        println!("Index di luar batas");
    }
}
```

### 4.2 Unwrap pada None/Err

```rust
// ❌ Rapuh — panic jika None
let value = some_option.unwrap();

// ✅ Lebih baik — berikan konteks
let value = some_option.expect("Nilai harus ada");

// ✅ Atau handle kedua kasus
match some_option {
    Some(v) => println!("{v}"),
    None => println!("Tidak ada nilai"),
}
```

### 4.3 Integer Overflow

```rust
// Debug mode: panic pada overflow
// Release mode: wrapping (two's complement)

let x: u8 = 255;
let wrapped = x.wrapping_add(1);   // 0
let saturated = x.saturating_add(1);  // 255
let checked = x.checked_add(1);   // None
```

## Bab 5: Anti-Pattern Performa

<Badge variant="orange">Menengah</Badge>

### 5.1 Obsesi Clone

```rust
// ❌ BURUK: cloning tidak perlu di hot path
fn process(data: Vec<String>) -> Vec<String> {
    let mut result = Vec::new();
    for item in &data {
        result.push(item.clone());
    }
    result
}

// ✅ BAIK: pinjam atau pindahkan
fn process(data: &[String]) -> Vec<String> {
    data.to_vec()
}
```

### 5.2 Alokasi Tidak Perlu

```rust
// ❌ BURUK: alokasi String ketika &str sudah cukup
fn examine(s: String) { println!("{s}"); }

// ✅ BAIK: gunakan &str
fn examine(s: &str) { println!("{s}"); }
```

### 5.3 Menggunakan `collect()` Tidak Perlu

```rust
// ❌ BURUK: mengumpulkan ke Vec antara
let sum: i32 = vec![1, 2, 3, 4, 5]
    .iter()
    .map(|x| x * 2)
    .collect::<Vec<_>>()  // Alokasi antara tidak perlu!
    .iter()
    .sum();

// ✅ BAIK: chain langsung
let sum: i32 = vec![1, 2, 3, 4, 5]
    .iter()
    .map(|x| x * 2)
    .sum();  // Langsung, tanpa alokasi
```

### 5.4 Optimasi Prematur

```rust
// ❌ BURUK: over-engineering sebelum mengukur
// Gunakan unsafe, generics kompleks, atau struktur data eksotis
// sebelum profiling menunjukkan mereka diperlukan

// ✅ BAIK: ukur dulu dengan alat profiling
// Kemudian optimasi hot spots (Prinsip Pareto: 20% kode = 80% waktu)
```

### Trait Umum

| Trait | Method | Penggunaan |
|-------|--------|-----------|
| `Clone` | `.clone()` | Deep copy |
| `Copy` | Implicit bitwise copy | Tipe stack-only |
| `Debug` | Format `{:?}` | Debug output |
| `Display` | Format `{}` | User-facing output |
| `PartialEq` | `==`, `!=` | Perbandingan kesamaan |
| `Eq` | (tanpa method) | Kesamaan penuh |
| `Hash` | `.hash()` | Komputasi hash |
| `Default` | `T::default()` | Nilai default |
| `Iterator` | `.next()` | Iterasi |
| `From` / `Into` | `.from()` / `.into()` | Konversi tipe |

### Konversi Tipe

```rust
// Numerik
let y: f64 = 42 as f64;

// String ke number

// Number ke string
let s = 42.to_string();

// String ke &str
let r: &str = &String::from("hello");

// &str ke String
let s = "hello".to_string();
let s = String::from("hello");

// Vec ke slice
let s: &[i32] = &vec![1, 2, 3];
```

| **2015** | 2015 | Rust stable awal |

## Glosarium

| Istilah | Definisi |
|---------|----------|
| **Ownership** | Sistem Rust untuk mengelola memori — setiap nilai memiliki tepat satu pemilik |
| **Borrow** | Akses sementara ke nilai tanpa mengambil kepemilikan |
| **Reference** | Pointer yang dipinjam (`&T` atau `&mut T`) |
| **Lifetime** | Scope waktu kompilasi yang memastikan reference tetap valid |
| **Move** | Transfer kepemilikan dari satu variabel ke variabel lain |
| **Trait** | Antarmuka perilaku bersama (mirip interface di bahasa lain) |
| **Generics** | Parameter tipe yang membuat fungsi/struct bekerja dengan banyak tipe |
| **Enum** | Tipe data aljabar — nilai bisa salah satu dari beberapa varian |
| **Panic** | Error unrecoverable yang meng-unwind stack |
| **Result** | Error handling recoverable — `Ok(T)` atau `Err(E)` |
| **Option** | Nilai opsional — `Some(T)` atau `None` |
| **Module** | Namespace yang mengatur kode dan mengontrol visibilitas |
| **Crate** | Paket kode Rust (library atau binary) |
| **Macro** | Kode yang menghasilkan kode saat kompilasi |
| **Closure** | Fungsi anonim yang menangkap lingkungannya |
| **Iterator** | Trait untuk menghasilkan urutan nilai |
| **Smart pointer** | Tipe yang mengelola memori heap (Box, Rc, Arc) |
| **Future** | Komputasi asinkron yang belum selesai |
| **Pin** | Memastikan nilai tidak bisa dipindahkan di memori |
| **Unsafe** | Mode Rust yang melewati beberapa jaminan keamanan |
| **FFI** | Foreign Function Interface — memanggil kode di bahasa lain |
| **Monomorfisasi** | Ekspansi waktu kompilasi dari generics ke tipe konkret |
| **NLL** | Non-Lexical Lifetimes — borrow checker per penggunaan |
| **GAT** | Generic Associated Type — associated type dengan generics sendiri |
| **SIMD** | Single Instruction, Multiple Data — instruksi CPU paralel |
