The `<Timeline>` component renders a vertical, chronological timeline with connecting lines, optional icons, and color-coded dots — perfect for project histories, roadmaps, release notes, career highlights, and step-by-step progressions.

Every `TimelineItem` is a data container — rendering and layout is handled by the parent `<Timeline>`.

---

## 7. Component API Reference

| Prop | Component | Type | Default | Description |
| :--- | :--- | :---: | :---: | :--- |
| `title` | `TimelineItem` | string | — | **Required.** Heading text for the timeline entry |
| `time` | `TimelineItem` | string | — | Optional date/time label shown in a pill badge |
| `icon` | `TimelineItem` | string | — | Optional icon name (uses the [same icon map](/blog/demo-mdx-components#1-badge-component) as Badge — 40+ options like `zap`, `rocket`, `star`, `check`) |
| `color` | `TimelineItem` | string | `brand` | Dot color variant: `brand`, `success`, `warning`, `danger`, `info` |
| `children` | `TimelineItem` | ReactNode | — | Any content — paragraphs, code blocks, lists, nested components |

### Hover Interactions

Each timeline item has **hover effects**:
- The dot/icon scales up to **110%** with an enhanced shadow
- The time badge changes color to the brand accent
- These add subtle interactivity without overwhelming the content

<Callout type="tip" title="Pro Tip">
  For the best results with code blocks inside timeline items, wrap them in a `<div>` as shown in the examples above. This ensures MDX v3 correctly parses the Markdown content and avoids rendering issues.
</Callout>

## 8. Comparison: Timeline vs. Steps

Both components display sequential content vertically, but they serve different purposes:

| Aspect | `<Timeline>` | `<Steps>` |
| :--- | :--- | :--- |
| **Best for** | Chronological events, histories, roadmaps | Step-by-step guides, tutorials, instructions |
| **Dot style** | Colored dot or icon (five color variants) | Numbered circle or icon (no color variants) |
| **Time label** | ✅ `time` prop for dates | ❌ No time support |
| **Connector** | Neutral border-colored line | Brand-colored gradient line |
| **Emphasis** | When something happened | What to do next |

**Use `<Steps>` when** you're writing a tutorial with numbered steps that users follow sequentially.

**Use `<Timeline>` when** you're showing a chronological sequence of events, releases, or milestones.

---

<Callout type="info" title="Getting Started">
  The Timeline component is available globally in any `.mdx` file — no import needed. Start by wrapping your items in `<Timeline>` and adding `<TimelineItem>` with at least a `title` prop. Everything else is optional!
</Callout>
