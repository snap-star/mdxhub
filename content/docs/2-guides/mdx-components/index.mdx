This project registers a set of custom React components that are **globally available** in every `.md` and `.mdx` file — no imports needed.

| Component | Description |
| :--- | :--- |
| [Tabs](/docs/2-guides/mdx-components/tabs) | Tabbed interface for switching content panels |
| [Steps](/docs/2-guides/mdx-components/steps) | Numbered step-by-step guide |
| [Mermaid](/docs/2-guides/mdx-components/mermaid) | Diagrams from plain text (flowcharts, sequence, pie, etc.) |
| [Callout](/docs/2-guides/mdx-components/callout) | Styled callout boxes for tips, warnings, notes |
| [VideoEmbed](/docs/2-guides/mdx-components/video-embed) | YouTube and iframe video embeds |
| [Badge](/docs/2-guides/mdx-components/badge) | Colorful pill labels with icons |
| [Tooltip](/docs/2-guides/mdx-components/tooltip) | Floating labels on hover/focus |
| [Image Lightbox](/docs/2-guides/mdx-components/image-lightbox) | Click-to-zoom for images (built-in) |
| [ProfileBadge](/docs/2-guides/mdx-components/profile-badge) | Author profile card |
| [CCLicense](/docs/2-guides/mdx-components/cc-license) | Creative Commons license badge |
| [AuthorCard](/docs/2-guides/mdx-components/author-card) | Author avatar, bio, and social links |
| [Code Block](/docs/2-guides/mdx-components/code-block) | Syntax-highlighted fenced code blocks (built-in) |
| [CodeSandbox](/docs/2-guides/mdx-components/code-sandbox) | Live editable code sandbox |
| [Accordion](/docs/2-guides/mdx-components/accordion) | Expandable/collapsible sections |
| [CardGrid](/docs/2-guides/mdx-components/card-grid) | Responsive grid of cards |
| [CodeGroup](/docs/2-guides/mdx-components/code-group) | Same code in multiple languages via tabs |
| [Timeline](/docs/2-guides/mdx-components/timeline) | Chronological vertical timeline |
| [Chart](/docs/2-guides/mdx-components/chart) | SVG bar, line, area, and pie charts |
| [FileTree](/docs/2-guides/mdx-components/file-tree) | Recursive directory tree with expand/collapse |
| [FAQ](/docs/2-guides/mdx-components/faq) | SEO-friendly accordion with FAQPage structured data |
| [NewsletterSubscribe](/docs/2-guides/mdx-components/newsletter) | Email subscription card |
