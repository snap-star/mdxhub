The `<Chart>` component renders lightweight SVG charts directly from data — no external dependencies. Supports bar, line, area, and pie/donut chart types. Colors cycle through the site's `--chart-1` through `--chart-5` CSS variables and adapt to light/dark mode automatically.

### Props

| Prop | Type | Default | Description |
| :--- | :--- | :---: | :--- |
| `type` | string | `"bar"` | Chart type: `bar`, `line`, `area`, or `pie` |
| `data` | array | — | Array of `{ label, value }` objects (required) |
| `title` | string | — | Optional heading displayed above the chart |
| `height` | number | `300` | Chart height in pixels |
| `donut` | boolean | `false` | When `true` and `type="pie"`, renders a donut chart with a center hole |
| `className` | string | `""` | Additional CSS classes |

### Usage

#### Bar Chart

```mdx
<Chart
  type="bar"
  data={[
    { label: "React", value: 42 },
    { label: "Vue", value: 28 },
    { label: "Svelte", value: 18 },
    { label: "Solid", value: 12 },
  ]}
  title="Framework Popularity (2026)"
/>
```

### Notes

- Charts are **pure SVG** — no external rendering libraries required
- Colors use `--chart-1` through `--chart-5` CSS variables, matching the site's light and dark themes automatically
- For complex diagrams (flowcharts, sequence diagrams, class diagrams), use the [`<Mermaid>`](/docs/2-guides/mdx-components/mermaid) component instead
